## How to steer this file

The "Next step" and "Blockers / notes" sections below come from trailers on
your most recent commit message:

```bash
git commit -m "feat(x): short subject" -m "Next: wire up Y" -m "Blocked-by: waiting on API key from ops"
```

Omit a trailer and its section keeps whatever it already said — the hook never
invents a plan or a blocker, so nothing resets to empty just because a commit
didn't mention it. Use `Blocked-by: none` (or similar) to explicitly clear it.

## What happened last

**feat: migrate section/resource/news/organization services off localStorage** _(2026-08-18, Gino Carrasco)_

All four feature services now talk to the maplibera-backend API instead of
persisting to localStorage. Each service's public shape (private signal +
computed) stays the same per the project's service convention, but every
mutating method is now async and entities are keyed by a stable backend
`id` instead of the editable `slug`.

Component-level specs use a FakeXService test double per feature (see
guide/testing/fake-section-service.ts) rather than mocking HTTP directly,
so they stay decoupled from wire format and don't re-implement the
staleLanguages diffing logic that now lives server-side.

Also adds /backend/* proxy routing (proxy.conf.json) and generic
actionFailedNotice/actionFailedDismiss i18n copy for the new class of
network-failure errors these async calls can now hit.
