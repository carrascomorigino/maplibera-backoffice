# .claude-resume.md

Session resume note. **Read this file first when starting a new session** — it
says what the last commit did, what's next, and what's blocking. For the full
picture (stack, architecture, feature status) see
[CLAUDE_CONTEXT.md](CLAUDE_CONTEXT.md).

This file is auto-loaded: [.claude/CLAUDE.md](.claude/CLAUDE.md) is Claude
Code's project-instructions file and points here, so any session opened in
this repo reads it automatically before doing anything else.

## How to steer this file

The "Next step" and "Blockers / notes" sections below come from trailers on
your most recent commit message:

```bash
git commit -m "feat(x): short subject" -m "Next: wire up Y" -m "Blocked-by: waiting on API key from ops"
```

Omit a trailer and its section keeps whatever it already said — the hook never
invents a plan or a blocker, so nothing resets to empty just because a commit
didn't mention it. Use `Blocked-by: none` (or similar) to explicitly clear it.
