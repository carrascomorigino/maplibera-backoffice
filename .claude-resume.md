## How to steer this file

The "Next step" and "Blockers / notes" sections below come from trailers on
your most recent commit message:

```bash
git commit -m "feat(x): short subject" -m "Next: wire up Y" -m "Blocked-by: waiting on API key from ops"
```

Omit a trailer and its section keeps whatever it already said — the hook never
invents a plan or a blocker, so nothing resets to empty just because a commit
didn't mention it. Use `Blocked-by: none` (or similar) to explicitly clear it.
